# PolarOps

Integrated Polar Expedition Logistics and Asset Management System — SIH26062 — Team TechNexus.

Offline-first system for cargo tracking, inventory, personnel movement, and emergency
response for Indian Antarctic expeditions.

## Folder structure

- `frontend/` — React + Vite app (Frontend developer)
- `backend/` — FastAPI app (Backend developer)
- `db/` — database schema, migrations, seed data (Database member)
- `design/` — Figma links, design tokens, screen exports (UI/UX Designer)
- `notebooks/` — forecasting and optimization prototypes (AI/ML members)
- `docs/` — architecture notes and the API contract

## Run it locally (once backend and db are set up)

    cp .env.example .env        # fill in real values
    docker compose up --build

Frontend: http://localhost:5173
Backend docs: http://localhost:8000/docs
